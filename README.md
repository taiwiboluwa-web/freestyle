# Freestyle — Creative Studio

A redesigned, Vercel-ready Next.js 16 landing page for Freestyle.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production

```bash
npm run build
npm run start
```

The project is configured for Vercel with `vercel.json`. No server-side secrets are required for the landing page.
